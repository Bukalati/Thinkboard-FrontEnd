# Think Board

اپلیکیشن یادداشت‌برداری — پروژه‌ی مینی بوت‌کمپ فرانت‌اند.

## تکنولوژی‌ها
- React + TypeScript + Vite
- Tailwind CSS v4
- React Router
- Lucide Icons

## ویژگی‌ها
- CRUD کامل یادداشت‌ها با اتصال به API واقعی
- جستجو و مرتب‌سازی کلاینت‌ساید
- Loading/Error/Empty state
- Confirmation قبل از حذف + Toast
- طراحی کاملاً Responsive و RTL

## اجرا
\`\`\`bash
npm install
npm run dev
\`\`\`
